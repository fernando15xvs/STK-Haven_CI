# STK Haven PNG pilots

Four transparent RGBA PNG poses for each of three exercise IDs are generated by the original illustrative authoring script `tool/exercise_png_pilots/generate_pilots.py`. Run from `apps/app_mobile` with `python3 -m pip install Pillow && python3 tool/exercise_png_pilots/generate_pilots.py`. Images remain QA pilots, not professionally audited anatomical plates. The public CI regenerates these files before Flutter tests/builds.
