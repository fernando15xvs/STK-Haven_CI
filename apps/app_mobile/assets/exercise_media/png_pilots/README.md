# STK Haven · Anatomía ilustrada realista (12 PNG)

Estos 12 archivos PNG fueron generados como ilustraciones originales para los tres ejercicios piloto, y son significativamente distintos de los bocetos procedurales anteriores. En revisión: **no cuentan con aprobación profesional anatómica o biomecánica**. Cada ejercicio tiene cuatro posiciones, un fondo con alfa transparente y resaltados rojo=principal / azul=secundario. Deben mantenerse desactivados sin la bandera de compilación `STK_PNG_PILOTS=true`. Prohibido presentarlos como guía definitiva hasta revisión humana.

**No ejecutar** el generador procedimental anterior; fue retirado. `tool/exercise_png_pilots/verify_realistic_pilots.py` valida SHA-256, formato, cobertura y colores antes de incluir recursos. No GIF, no solicitudes web, no datos del usuario.
